# Superstore SQL Analysis

SQL Server analysis of US retail sales: where discounts turn sales into losses.

## Dataset

Superstore sales data from Kaggle: [add Kaggle link here]

The CSV isn't stored in this repo. Download it from the Kaggle page to run the scripts.

## Tools

- SQL Server

## Repo structure

```
superstore-sql-analysis/
├── README.md
├── sql/
│   ├── 01_setup.sql               ← import notes, build script, validation checks
│   ├── 02_exploration.sql         ← exploration queries E1–E10
│   └── 03_business_questions.sql  ← business questions Q1–Q13
├── results/                       ← CSV exports of key query results
└── images/                        ← charts and screenshots
```

## How to run

1. Download the dataset from Kaggle.
2. Run `sql/01_setup.sql` to import and validate the data.
3. Run `sql/02_exploration.sql` and `sql/03_business_questions.sql`.
